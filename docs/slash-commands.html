斜杠命令

Hermes Agent 内置的全部斜杠命令。通用表示命令行与消息平台（Telegram 等）都能用； 仅命令行只在 CLI/TUI 界面里存在，聊天里发出去不会有反应。

会话与会话控制42 条

命令可用范围说明
/agents通用查看活跃 agent 与运行中的任务 别名 /tasks
/bg通用在独立的后台会话里跑一个 prompt
/branch通用从当前会话分叉出新线程 别名 /fork
/btw通用对当前对话提个侧问，不打断主线
/compress通用压缩对话上下文（可控成本） 别名 /compact
/context通用查看上下文窗口明细（占用、分类、压缩、吞吐） 别名 /ctx
/egress通用查看 Docker 出口代理状态
/goal通用设定一个跨回合持续推进、直到达成的长期目标
/heartbeat通用设一个空闲时自动重入本会话的循环 prompt 别名 /hb
/loop通用在本会话里按固定间隔重复跑一个 prompt 别名 /proactive
/moa通用用默认 Mixture of Agents 预设跑一次，然后恢复原模型
/new通用开一个新会话（全新会话 ID 与历史） 别名 /reset
/plan通用写一份 markdown 实施计划到 .hermes/plans/，不执行
/queue通用把提问排到下一轮，或列出/编辑/删除队列 别名 /q
/refine通用立即复盘本对话，把教训存进记忆与技能
/resume通用恢复一个此前命名过的会话
/retry通用重发上一条消息
/review通用起一个独立 subagent 评审刚讨论的工作
/rollback通用列出或恢复文件系统检查点
/save通用导出当前对话
/sessions通用浏览并恢复历史会话
/status通用查看会话、模型、token 与上下文信息
/steer通用在下次工具调用之后注入消息，不打断当前回合
/stop通用杀掉所有正在跑的后台进程
/subgoal通用给进行中的目标追加判据
/title通用给当前会话命名
/undo通用回退 N 轮用户发言并重新提问（默认 1）
/approve仅消息平台批准一条待审的危险命令
/deny仅消息平台拒绝一条待审的危险命令（可附理由）
/pause仅消息平台全局暂停新工作（紧急刹车），/pause off 恢复
/restart仅消息平台优雅重启网关（先排空在跑的回合）
/sethome仅消息平台把当前聊天设为 home 频道 别名 /set-home
/start仅消息平台确认平台启动 ping（不回话）
/topic仅消息平台启用或查看 Telegram 私聊话题会话
/clear仅命令行清屏并开一个新会话
/handoff仅命令行把本会话移交给某个消息平台
/history仅命令行显示对话历史
/journey仅命令行打开学习轨迹时间线 别名 /learning、/memory-graph
/prompt仅命令行在编辑器里写 markdown 形式的下一条提问 别名 /compose
/redraw仅命令行强制重绘界面（终端显示漂移时恢复）
/snapshot仅命令行创建或恢复 Hermes 配置/状态快照 别名 /snap
/worktree仅命令行查看、创建或清理隔离的 git worktree

/wake仅命令行开关「Hey Hermes」唤醒词监听
